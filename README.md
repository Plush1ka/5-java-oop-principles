## Сборка и запуск тестов

Требуется JDK 21 и Maven 3.8+.

```bash
mvn test              # прогнать тесты всех заданий
mvn -pl task01 test   # прогнать тесты одного задания
mvn -fae test         # не останавливаться на первом упавшем задании
```

Пока решение не написано, тесты задания падают — это нормально.
Задание считается выполненным, когда `mvn -pl taskNN test` проходит успешно.

## Структура модуля

```
taskNN/
├── pom.xml
├── README.md                                            условие задания
└── src
    ├── main/java/com/example/taskNN/TaskNNMain.java      здесь пишется решение
    └── test/java/com/example/taskNN/TaskNNMainTest.java  тесты, менять их не нужно
```

Тесты проверяют только формальные признаки выполнения задачи
и не заменяют проверку качества выполнения преподавателем.
